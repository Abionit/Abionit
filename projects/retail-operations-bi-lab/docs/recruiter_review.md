# Recruiter Review

## What This Project Is

Retail Operations BI Lab is a practical data project that connects data engineering and business intelligence.

It starts with operational retail data and turns it into a Power BI-ready analytical model.

## Problem Solved

Retail teams need more than total sales. They need to understand:

- which categories drive revenue,
- where margin is under pressure,
- which stores have stockout risk,
- which delivery methods create delays,
- which customer segments contribute the most value.

The project solves this by creating a clean data model that connects sales, inventory, customers, products, stores, and deliveries.

## Evidence To Review

- Python ETL scripts in `src/`.
- Power BI-ready tables generated under `data/powerbi/`.
- SQL queries in `sql/analytics_queries.sql`.
- DAX measures in `powerbi/measures.dax`.
- Dashboard blueprint in `powerbi/report_blueprint.md`.
- Business reasoning in `docs/business_case.md`.
- Automated tests in `tests/`.

## Why It Matters For Data Analyst Roles

The project shows the ability to translate business questions into metrics, model data for reporting, define DAX measures, and design dashboard pages around decisions.

## Why It Matters For Data Engineer Roles

The project shows source integration, validation, transformation, analytical modeling, reproducible outputs, tests, and a structure that can evolve toward cloud pipelines.

## Main Tools

SQL, Python, pandas, Power BI model design, DAX, star schema, data quality checks, Git-ready project structure.
